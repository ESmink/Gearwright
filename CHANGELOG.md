# Changelog

All notable changes are documented here. Each entry that changes persisted data must name its schema transition and migration test.

## 0.1.0 - unreleased

- Established the Gearwright mod identity for Vintage Story 1.22.3.
- Added `/gearwright` as an installation and save-state status command.
- Added world-state schema 1 with unknown-field preservation, schema-0 migration, corrupt-data protection, and newer-schema read-only behavior.
- Added executable contracts for creation, migration, round trips, corrupt data, unknown formats, and future-schema write protection.
- Added deterministic PowerShell graphics tooling for primitive-based shape models and composited game-style textures, plus logical asset discovery and path-safe recipes.
- Added the creative-mode Potter's Profile Tool as the first runtime item generated by the graphics pipeline, with a composited material atlas and primitive model.
- Made active development installation part of the agent completion contract and added SHA-256 verification after copying the newest package to the discovered Mods folder.
- Fixed `/gearwright` command registration by declaring the ordinary `chat` privilege required by Vintage Story's command API.
- Added a tag-driven GitHub release workflow that builds against the declared Vintage Story version and publishes the verified mod zip with a SHA-256 checksum.
