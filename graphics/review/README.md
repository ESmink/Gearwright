# Review sources

Files here build managed human-decision packages. They are development sources, never runtime mod assets.

Every review builder writes its temporary package below `generated/<feature>-review/.current-build/` and atomically replaces one fixed `generated/<feature>-review/current/` directory. Do not write candidates to `assets/gearwright/`, and do not create a new revision directory for each run. `runtimePromotion: true` in a review manifest means that the approved reference is eligible for a separate, explicit runtime promotion; it does not change the review package's output directory.

`large_bellows_frame.py` owns `generated/large-bellows-frame-review/current/`. The maintainer approved original A with horizontal rails at the top of the native base, retaining A's original brace height, bearing seats and top crosspiece. Runtime geometry is in `graphics/models/parts/large_bellows_frame.py`; `a-braced-uprights/rest.shape.json` is the approved reference. Rejected revisions are removed. The base footprint, oak grain and thin plank construction are retained, with shallow inside relief to clear the leather. The lower chamber now breathes during top drive. The generator checks the frame against the animated body and drive every five degrees, plus the new rails against the other frame boards, and renders seven views at four phases. Run `python -m graphics.review.large_bellows_frame --vintage-story <installation> --render` with `PYTHONPATH=tools/graphics`.

`large_bellows.py` owns `generated/large-bellows-review/current/` and reads the bellows body from the installed game. A is approved and promoted: bottom drive uses a reinforced oak pitman, reducing rocker and short lift links. `large_bellows_top.py` adapts the same construction to drive the top board directly, while the lower board follows suction upward and drops to refill on the return stroke. The both-shafts state selects only the lower linkage. Rope and wraparound alternatives are removed. The lower drive's upper reservoir follows incoming air minus nozzle outflow. Review states cover one-sided and through shafts and a shared pump; the generator checks native board attachment points and shaft, frame and chamber clearance every five degrees. Run `python -m graphics.review.large_bellows --vintage-story <installation> --render` with `PYTHONPATH=tools/graphics`. Runtime attachment geometry is owned by `graphics/models/large_bellows.py`; the original game body is never copied into tracked assets. The upper attachment moves inward along the board to clear the shaft throughout the stroke.

`lateral_drive_mount.py` owns only `generated/lateral-drive-mount-review/current/` and reproduces approved A with the requested centering. One rod sits at zero; two, three and four rods use the minimum practical symmetric group at 1.4-model-unit spacing. The runtime source is `graphics/models/parts/reciprocating_drive.py`. States include one pump, opposed and adjacent pairs, three pumps, four pumps and the isolated dry mechanism. Both shaft forms keep rotating pins clear of bearing windows, guides and crossheads. `lateral_drive_clearance.py` checks transformed cuboids against neighboring devices, the shaft and each rod's own crosshead and pressure head; its default sweep samples every degree. The manifest records approval and runtime promotion; B has been removed.

`reciprocating_pump_refinement.py` owns `generated/pump-refinement-review/current/` and reproduces approved A. Its folded copper pipes descend 0.9 model units inboard so the complete terminal collars remain exposed underneath. The continuous wet body removes intersecting walls and the out-of-block inlet shadow; its floor rises 0.495 units to match the simulation's clearance volume. The crank, piston, roof checks and oak cradle retain their geometry. Runtime geometry lives in `graphics/models/parts/reciprocating_pump_wet_end.py`. The review includes a constant-height two-litre surface, displacement-driven discharge/refill, contact poses, neighboring pipes and an illustrative blocked-output hold. Run `python -m graphics.review.reciprocating_pump_refinement` with `PYTHONPATH` set to `tools/graphics`, then open the package with the standard reviewer. B is removed; the manifest records the approval and requested narrower pipes.

`pipe_wood_supports.py` owns only `generated/pipe-wood-supports-review/current/` and reproduces the approved C design from `graphics/models/pipe_wood_support.py`, including the requested single diagonal braces and insulated crate mode. Twelve reusable parts build endpoint collars on pipe faces, one diagonal on each empty side and bottom, a sparse top, inset narrow-board lining, and a frame spanning all six block boundaries. The frame directly meets walls, ground, and adjacent frames. On open frames, a pipe above removes the platform; a terminal upward connection omits its middle plank. Insulated frames have recessed panels with openings sized for pipe ends, nozzles and sprinklers. Eighteen states include runs on both horizontal axes, a vertical elbow, a junction, all six ports, a sprinkler, the actual upward barrel nozzle, and six insulated assemblies. Tests check transformed wood/pipe intersections for all 64 port layouts with and without lining, nozzle clearance on all six faces, matching frame rims and collars across block boundaries, and both open top variants. Run `python -m graphics.review.pipe_wood_supports --render` with `PYTHONPATH` set to `tools/graphics`; this uses the standard photoshoot to produce seven fixed views per state and a labeled contact sheet. Open the package with `python -m gearwright_graphics.review_model --review generated/pipe-wood-supports-review/current`.

`small_flywheel.py` owns only `generated/small-flywheel-review/current/`. It reproduces the four exact 3×3×1 candidates used to choose the completed Small Flywheel. E4 (`model-e4-iron-eight-way-frame`) is the approved runtime design. Omit `--approved` to compare the archived candidates, or pass that candidate ID to reproduce the closed decision package.

The current set keeps E1 through E3 and adds E4: eight straight stripped-oak arms enclosed by a large octagonal iron socket frame, with narrow iron straps continuing along the unbent arms.

`slingshot_workflow.py` owns only `generated/slingshot-review/current/`. Each run replaces that fixed directory, so repeated review rounds do not create new revision trees or orphaned scripts. The generated ownership manifest records the source, candidates, and decision.

`overrunning_coupling.py` owns only `generated/overrunning-coupling-review/current/`. Its locking-interface round keeps the approved A2 frame, four wooden input supports, and three-arm orbit while comparing three complete tooth-and-pawl pairs: a fifteen-position smooth brass ramp with a restored long hook, a twelve-pocket reinforced-oak ring with thin brass glide plates and a broad drop bar, and a nine-point swept wheel with the concept-art crook. Option A now uses one narrow bronze contact stick truncated at the former club shoulder, carries its visible follower cap with that stick, overlaps the oak rim and thin brass tire to hide sectional gaps, and gives the diagnostic tooth pass four explicit recovery frames after its frame-23 peak. The circled clevis side plates are removed, and every flat locking shoulder meets its pawl on an exact shared plane. Full-assembly, isolated-interface, isolated-input, and isolated-output states remain review-only until the maintainer approves one pair.

`lateral_motion_system.py` owns only `generated/lateral-motion-review/current/`. A7 remains the animated double-acting reference, A9 the unframed one-block baseline, and A10 the accepted two-block bottom-fed design. A11 removes A10's lower service block while retaining the three-unit crank throw, six-unit stroke, eight-unit piston, glass chamber, and centered side-face connections at y=-16. It does not enter the chamber through those side walls: each 4-by-4 line turns into a flush shared-wall drop, runs inward at y=-21.25, then turns up through its own uncapped 3-by-3 reservoir-floor port. The slightly recessed inlet check lifts into the chamber on suction without entering the piston envelope, and the outlet check drops into its riser on pressure. A low oak cradle stand now appears only in A11's supported downward-facing pump-bottom, cutaway, and pipe-fit states; side- and upward-facing states show the unframed pump. Broad runners, four short legs, split saddles, horizontal corner struts, stout knees, and local iron plates transfer the vessel load into the block below without surrounding the chamber as a permanent cage. The exact `pipe-fit` state places complete horizontal neighbor blocks at x=-16 and x=16. All three single-acting candidates retain paired output-side air checks, animation, a true one-sided crank, and no visible example liquid. The checks are now vertical and seated directly in two openings on the output half of the split pressure ceiling: the atmospheric intake is nearly flush and opens downward into the chamber, while the exhaust has a short exposed cage and opens upward. The rejected side branches are gone, the output chamber wall is solid, and the complete terminal rim of the main output coupling is bronze, supplying a second restrained direction cue without changing pipe alignment. The recessed rod well keeps its flush bronze stuffing plate; narrowed guides, the inward valve cage, and the piston remain clear through the full stroke. They remain approval-only, and the old automatic-bellows candidate is superseded by the approved large-bellows workflow above.

The normal command reproduces the approved C result. Pass `--open` only to restart the three-candidate workflow test. Approval applies to the fixture, not to a runtime slingshot.

From the repository root:

```powershell
$env:PYTHONPATH = "tools/graphics"
python graphics/review/small_flywheel.py --root .
python -m gearwright_graphics.review_model --review generated/small-flywheel-review/current

python graphics/review/slingshot_workflow.py --root .
.\tools\graphics\Review-Model.ps1 -PythonPath python -ReviewPath generated/slingshot-review/current

python graphics/review/overrunning_coupling.py --root .
.\tools\graphics\Review-Model.ps1 -PythonPath python -ReviewPath generated/overrunning-coupling-review/current

python graphics/review/lateral_motion_system.py --root .
.\tools\graphics\Review-Model.ps1 -PythonPath python -ReviewPath generated/lateral-motion-review/current
```

The slingshot is a test fixture for reviewing models and animations. Do not copy it into `graphics/models/`, `assets/gearwright/`, or gameplay code.
